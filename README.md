📶 Network Performance Analysis using Data Analytics & Visualization


📌 Project Overview

This project focuses on analyzing Wi-Fi network performance across different departments/hostels using data analytics and visualization techniques. The goal is to identify performance bottlenecks, congestion patterns, and optimization opportunities.

🎯 Problem Statement

With increasing number of connected devices, network performance degrades due to:

High user density
Uneven Access Point (AP) distribution
Signal strength variations
Time-based congestion

This project aims to analyze these factors and provide data-driven insights to improve network efficiency.


📊 Dataset Description
Type: Structured dataset (CSV format)

Data Includes:
Department / Location
Access Point (AP) Name & Type
IP Address
Number of connected devices
Network speed / throughput
Signal strength (RSSI)
Time-based usage data

Size: ~500+ rows (can vary)


⚙️ Preprocessing Steps
Data cleaning (handling missing/null values)
Removing duplicates
Feature selection
Formatting IP & categorical data
Normalization (if required)


📈 Exploratory Data Analysis (EDA)

The following visualizations were used:

Scatter Plots → Device vs Speed relationship

Heatmaps → Time-based congestion

Radar Charts → Multi-metric comparison

Violin & KDE Plots → Distribution analysis

3D Plots → Multi-variable interaction

Bubble Charts → Combined feature impact

Pairplots → Feature relationships

Swarmplots → Data density visualization

🔍 Key Insights

More devices → lower speed (negative correlation)

Peak congestion during evening/night hours

Strong signal → better performance

High variability → inconsistent user experience

Clear distinction between high and low performing zones
